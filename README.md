# SeguridadCriptografia
Proyecto de la materia Uso de álgebras modernas para seguridad y criptografía (Gpo 602)

## Area de Oportunidad
  * Revisar el tipo de docuentos que se tengan que entregar/revisar en la aplicacion
  * Conocer y hacer las plantillas de los documentos para simular las verificaciones
  * Verificar la seguridad de la pagina web

## Solucion
Asegurar la confidencialidad, integridad, disponibilidad y no repudio en los documentos hacia externos de las personas en situacion de migracion a traves de una firma digital.

## Beneficios
Plataforma amigable y eficiente para la firma digital de documentos

### Valor para Casa Monarca
El valor para casas Monarca es un proceso mejor estructurado de los documentos de las personas acogidas.

### Valor para Usuarios
El valor para los usuarios es una plataforma que permite guardar documentos de manera segura y guia al usuario en su proceso legal.
